Final Site Structure

All HTML, copy-paste templates, no build tools

├── css/
│   └── style.css           ← Single stylesheet (all pages)

└── images/
    ├── photos/             ← Gallery images go here
    └── books/              ← Book cover images go here

How to Add Content

New Blog Post
  1. Copy posts/template.html
  2. Rename to your-post-title.html
  3. Edit title, date, tags, and content
  4. Add a link entry in blog.html
New Book
  1. Open books.html
  2. Find the <!-- TEMPLATE --> block
  3. Copy & paste it
  4. Fill in title, author, status
New Quote
  1. Open quotes.html
  2. Find the <!-- TEMPLATE --> block
  3. Copy & paste it
  4. Fill in quote text and author
New Life Event
  1. Open life-events.html
  2. Find the <!-- TEMPLATE --> block
  3. Copy & paste it
  4. Fill in year, event, description

Blog Tags & Filtering

Each post entry in blog.html has data-tags attributes. Tag buttons at the top filter posts by showing/hiding entries — about 30 lines of vanilla JS. Tags are free-form — just add any new tag string and it works automatically.

Photos

Drop images into images/photos/. Add an <img> tag to the gallery grid in photos.html. Clicking opens a full-screen lightbox overlay. All images use loading="lazy" for fast page loads.
